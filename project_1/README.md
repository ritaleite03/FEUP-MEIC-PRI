# Medical Search with Semantic & Lexical Indexing – Project 1

## 📌 Overview

This project implements a **specialized medical search engine** for doctors and patients to retrieve reliable disease-related information.

Key components:

- Index medical documents using **Apache Solr**
- Implement three indexing strategies: **simple**, **complex**, and **complex with field weights**
- Hybrid search combining **lexical** and **semantic** approaches
- Relevance feedback via **Rocchio algorithm**
- Evaluation using **Mean Average Precision (MAP)**

## 📝 Features

- Medical document **indexing** (3 strategies)
- **Hybrid search**: lexical + semantic
- **Relevance feedback** with Rocchio algorithm
- Evaluation using **MAP**
